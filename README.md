# Indisciplinato 2027 – fornitori con Asti Slow Fashion

Pagina semplice per raccogliere, voce per voce, i fornitori possibili (nome, costo, link).
I dati restano nel browser di chi compila; si esportano con "Scarica Excel" (CSV).
Nessun collegamento a Drive o al gestionale.

Le voci e i budget (`const VOCI` in `index.html`) sono quelli del computo spese per Fondazione CRT
(`Computo_spese_Indisciplinato_Fondazione_CRT.xlsx`, cartella Drive "Pietro dati"): 25 voci, 7.882,22 €.
Per aggiornarli si modifica solo quella lista; gli `id` delle voci vanno lasciati uguali, così i fornitori già scritti restano collegati.
